# CIC Curriculum Explorer

Tools and a web interface for the Curriculum Improvement Cycle (CIC) Know-Do-Understand frameworks.

- [`model/`](model/): the curriculum data model (PostgreSQL schema and JSON Schema), the PDF extraction pipeline, the extracted data and the Curriculum Explorer website. See [model/README.md](model/README.md).

The source framework PDFs are not in this repository. To re-run the extraction, put them in a `frameworks/` folder at the repository root.
